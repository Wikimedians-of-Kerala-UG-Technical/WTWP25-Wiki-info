# WTWP25- Wiki-Dash

WikiDash is a modern and lightweight web dashboard developed as part of the WTWP25 initiative. It provides a cleaner and more structured way to explore Wikipedia content.

Instead of navigating through lengthy articles, users can quickly search any topic and view a concise summary, key information, and related images — all within a focused and user-friendly interface.

The project emphasizes simplicity, responsive design, and smooth interaction using core web technologies.

---

## Features

- Topic-based search
- Quick summary display
- Structured metadata view
- Related image gallery
- Trending search suggestions

---

## Tech Stack

- HTML5  
- CSS3  
- JavaScript  
- Wikipedia API  

---

Built with a focus on clarity, performance, and user experience without relying on heavy frameworks.
